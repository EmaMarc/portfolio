## Portfolio Atmosphere

Árbol:

```txt

├─ aura-smoke-cursor.tsx
├─ edge-mist.tsx

├─ portfolio-atmosphere.module.css
└─ portfolio-atmosphere.tsx
```

Integración:

- Importado en `src/app/layout.tsx`.
- Montado globalmente antes de `children`.
- El contenido queda por encima mediante wrapper `relative z-10`.

Implementación:

- `PortfolioAtmosphere` renderiza:
  - `<div aria-hidden="true" className={styles.root}>`
  - `AmbientLight`
  - `baseWash`
  - `topHighlight`
  - `EdgeMist`
  - `AuraSmokeCursor`
- `root` usa:
  - `position: fixed`
  - `inset: 0`
  - `z-index: 0`
  - `overflow: hidden`
  - `pointer-events: none`
  - `isolation: isolate`
  - fondo dark/burgundy por gradiente.

Tecnologías visuales usadas:

- DOM + CSS gradients/keyframes para Ambient Light y Edge Mist.
- Canvas 2D para Aura Smoke Cursor.
- No SVG dinámico.
- No librerías externas.

Client Component:

- Solo `aura-smoke-cursor.tsx` tiene `"use client"`.

Browser APIs usadas por Aura:

- `document.createElement("canvas")`
- `canvas.getContext("2d", { alpha: true })`
- `window.matchMedia("(pointer: fine)")`
- `window.matchMedia("(prefers-reduced-motion: reduce)")`
- `window.requestAnimationFrame`
- `window.cancelAnimationFrame`
- `performance.now`
- `window.addEventListener`
- `document.addEventListener`
- `document.hidden`

Eventos:

- `pointermove`
- `pointerleave`
- `resize`
- `blur`
- `visibilitychange`
- listeners `change` sobre media queries.

Reduced motion:

- JS no habilita Aura si `prefers-reduced-motion: reduce`.
- CSS desactiva animaciones de Ambient/Edge.
- CSS oculta `.auraSmokeCursorCanvas`.

Performance observable:

- No usa React state por frame.
- Usa refs y variables internas.
- `PUFF_COUNT = 16`.
- `CANVAS_DPR = 1`.
- RAF solo se mantiene si hay aura/puffs vivos.
- Limpieza de listeners en cleanup.
- `pointer-events: none`.
- En mobile `max-width: 640px` oculta top/bottom Edge Mist.
- Aura se muestra solo con `@media (pointer: fine)` y además ignora `event.pointerType === "touch"`.
